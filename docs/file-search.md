# 文件搜索

当前实现：V0.8；最后核对：2026-10-13。生产路径为 Spotlight 快速候选 + Rust 完整文件名遍历，不维护长期索引，不要求安装 rg。

## 入口与界面

Global Search 输入 `files` / File Search / “文件搜索”，执行普通 Action 进入主 Launcher 的二级工具页。该 Action 可配置本地 / 全局快捷键。普通 Launcher 查询、Current App 和内容输入不隐式触发文件检索。

- 非空单字符即可搜索；文件 / 文件夹 / 文档 / PDF / 图片 / 音频 / 视频 / 压缩包 / 代码等类型在计数和保存前过滤。
- Ctrl+Tab / Ctrl+Shift+Tab 切类型，↑ / ↓ 选择，Enter 打开，⌘K 打开对象操作。
- 结果是稳定的连续列表，没有分页按钮。已显示前缀不因晚到高分项重排；新查询、类型或范围变更重新取得结果。
- 滚动或方向键在末尾按需追加；鼠标加载不改变选择与滚动位置。加载失败保留已有结果，可重试。
- 右侧预览固定存在、跟随选择，没有 Preview Action / 开关 / 关闭入口。120ms 防抖并隔离迟到响应；对象 Actions 中仍预览原文件。
- 预览当前提供元数据和最多 64 KiB 的文本，不支持完整 PDF、图片、Office、音视频富预览。图标按类型分类，不为每行生成缩略图。
- 文件工具请求 920×600，Host 按屏幕约束；返回主页面恢复其宽度 / 高度逻辑。Esc 与父页面规则见 [Launcher 交互](launcher-interaction.md)。

## 匹配与完整性

名称归一为 NFC → full case fold → NFC，多个词都需命中 basename，标点按字面处理。普通名称和显式路径有独立字节边界；控制字符输入拒绝。

`~` / `~/…` 和中文全角 `～/…` 先通过与 Context 相同的路径展开器解析主目录，仍受原授权范围限制。显式目录浏览直接子项；已有文件定位该文件；未完整名称在父目录匹配。路径必须位于实际授权 roots 中，规范化和真实目标检查防止 `..` 或链接越界，不隐式扩大范围。

“不遗漏”仅指查询期间稳定、可读、允许范围中符合条件的对象，并要求遍历及临时存储无错误完成。Home 不等于所有磁盘。无法读取位置跳过并计数；其他 I/O、名称表示或存储错误标为 Partial，不能冒充完整结果。

范围由最多 8 个根、隐藏开关及最多 32 个排除目录名决定。空设置列表请求 Home，空实际授权范围保持停用。新配置包含隐藏文件，已有配置保留原值。不读取 gitignore，也不默认排除 node_modules、build、target、Library 或应用包。

符号链接本身可列出，但不递归其目录目标；不同路径的硬链接分别保留。内部查询临时目录排除。执行时重新校验路径、类型和链接目标，稳定行不等于跳过执行验证。

## 授权

启动、保存搜索设置和显式 Authorize saved directories 时准备访问；搜索代码不申请授权。macOS Host 恢复只读安全作用域书签并持有租约，发布实际有效范围。

取消、失败或无授权先撤销旧来源 / 目标，保持停用，不把空 roots 回退 Home。部分授权只搜索授权子范围；其他 Launcher 功能继续可用。完全磁盘访问只能在系统设置开启，文件夹选择不等于所有后代永远可读。

原生授权用 epoch、串行 worker 和 watchdog，旧面板 / 回调不能覆盖新设置；Dart 保存队列也检查 generation。同步 OS I/O 无法保证立即取消，过期结果完成后释放租约，不提前放开并发。

## 查询流水线

```text
输入 / 类型 / 范围版本
   ├─ 有界 Spotlight 快批 → 核验并显示早期候选
   └─ 输入稳定后完整遍历 → 查询临时记录
                              → 外部排序 / 未读尾部归并
                              → 按批次追加到稳定列表
```

Spotlight 返回多少、是否失败都不决定是否遍历。旧 Ripgrep / Combined 枚举和诊断入口只用于兼容，不是生产 UI 的引擎选择。

| 模块 | 职责 |
|---|---|
| `features/filesystem/search.rs` | 快批 / 扫描协调、系统能力、Candidate 与动作绑定 |
| `features/filesystem/scan.rs` | 名称匹配、过滤、完整遍历、临时记录 |
| `features/filesystem/result_store.rs` | 有界外部排序、未读尾部归并、失败重建 |
| `application/source_runtime.rs` | 通用异步来源 admission、取消、批次与版本校验 |
| `application/file_workspace.rs` | 文件配置、进度、冻结与原子稳定追加 |
| `application/object_actions.rs` | 按选中对象生成二级动作和凭证复验 |
| Platform `search_storage` / macOS `file_search` | 原始路径编码、私有临时目录与租约、固定 argv 的 mdfind |
| Flutter FileWorkspace / Session 协调器 | Delta 合并、查询 / 列表版本、返回位置与展示请求 |

## 资源与生命周期

遍历器一次读取一个目录，把待遍历目录写入磁盘 FIFO；不在内存收集全树，不为每项创建任务。必要属性以外不读正文、图标或项目数据。

命中写入权威二进制记录，flush 后推进可读边界。内部每批 64 项；排序段最多 512 项 / 1 MiB，最多 16 路归并。新增命中仅与未读尾部合并，已经展示的路径去重；失败重建从权威记录恢复，不因推进游标漏项。

查询、类型、范围、来源目录或会话变更撤销旧任务。worker 持有 admission 至真正结束；有界通道避免积压。临时目录使用私有权限和 lease 锁，释放引用后清理，异常退出的无活租约目录在后续准备时回收。

已加载候选和执行表随浏览量增长；Delta / 共享分块减少重复复制，不保证整 App 恒定 RSS。没有生产遍历的 50,000 项或首批满即完成上限。冷扫描和磁盘不足不能承诺固定耗时。

## 临时目录与回收站过滤

普通文件名搜索默认不遍历系统临时目录，以及 macOS `~/Library/Caches/<app>.ShipIt/` 更新器缓存、`~/.Trash/` 和 `~/Library/CloudStorage/<provider>/.Trash/` 回收站；Spotlight 快速候选也执行同一过滤，避免被排除的内容重新出现在列表中。系统临时路径由平台层发现，每次查询准备一次，过滤本身不增加逐条 IO。

不会只因名字是 `tmp` / `temp` 而排除项目目录，也不排除整片 `Library/Caches`、`.cache`、`.m2` 或 `node_modules`。这使仍有使用价值的配置文件保持可搜索。

不会排除 OneDrive 等云盘的普通文件夹，或项目内部同名 `.Trash` 文件夹；同名普通文件也保留。普通云盘目录的真实读取超时仍报告部分结果。

直接输入这些目录地址，或把其中的具体目录配置为搜索根，是明确搜索该目录的意图，仍可搜索；原有授权范围检查和用户设置的排除规则继续适用。默认搜索的完整性指上述规则界定的范围，不包括主动排除的临时目录与回收站。

## 部分结果与诊断

无权限的子目录单独计数并跳过，不在查询期间申请权限。扫描时已经消失的子项安静跳过；用户配置的根目录消失仍属于可处理的范围异常。其他扫描异常保留已找到结果，并显示实际问题数量；黄色提示条悬停显示具体原因。最多 8 条原因写入 `launcher.log`，不记录查询正文。配置根目录被移除、无法表示的文件名、读写失败等不能统一归因于权限不足；重试会重新扫描当前范围。
