# 文件搜索

两端共用 Rust 文件名遍历。macOS 默认用 Spotlight 提供快批。Windows 默认
使用 Combined，也可选 Everything、Windows Search、Ripgrep 或直接遍历。
依赖与设置入口见 [Windows 指南](windows.md#文件搜索)。

## 入口与界面

Global Search 输入 `files` / File Search / “文件搜索”，执行普通 Action 进入主 Launcher 的二级工具页。该 Action 可配置本地 / 全局快捷键。普通 Launcher 查询、Current App 和内容输入不隐式触发文件检索。

- 非空单字符即可搜索；文件 / 文件夹 / 文档 / PDF / 图片 / 音频 / 视频 / 压缩包 / 代码等类型在计数和保存前过滤。
- Tab / Shift+Tab 切类型（兼容 Ctrl+Tab / Ctrl+Shift+Tab），↑ / ↓ 选择，Enter 打开，⌘K（Windows Ctrl+K）打开对象操作。切换保留查询与输入焦点；中文组词期间不切换。
- 结果是稳定的连续列表，滚动追加，并提供加载更多入口。已显示前缀不因晚到高分项重排；新查询、类型或范围变更重新取得结果。
- 滚动或方向键在末尾按需追加，加载期间按钮显示进度。鼠标加载保留选择与滚动位置。
  通过方向键请求时，只有仍停在触发加载的行上才自动移到新增结果。加载失败保留已有
  结果，可重试。若翻完当前批次后遍历发现更多文件，加载入口重新出现。
- 查询和类型变化后默认不选中候选项；首次方向键选中第一项，再按空格预览。手动选择随结果追加保留。
- 不保留固定预览区，选中行眼睛按钮或 ⌘Y（Windows Ctrl+Y） 打开系统预览；浏览结果后可用空格切换，查询中的空格和输入法保持原义。关闭保留查询和选择，详见 [系统预览](native-preview.md)。
- 列表保留文件名、路径和类型图标；系统负责预览格式和显示效果，只有明确打开时才准备内容，不为每行生成缩略图。
- 文件工具请求 648×600，Host 按屏幕约束；返回主页面恢复其宽度 / 高度逻辑。Esc 与父页面规则见 [Launcher 交互](launcher-interaction.md)。

## 匹配与完整性

名称归一为 NFC → full case fold → NFC，多个词都需命中 basename，标点按字面处理。两端完整遍历均支持中文全拼和首字母匹配。普通名称和显式路径有独立字节边界，控制字符输入会被拒绝。

`~` / `~/…` 和中文全角 `～/…` 先通过与 Context 相同的路径展开器解析主目录，仍受原授权范围限制。显式目录浏览直接子项；已有文件定位该文件；未完整名称在父目录匹配。路径必须位于实际授权 roots 中，规范化和真实目标检查防止 `..` 或链接越界，不隐式扩大范围。

“不遗漏”仅指查询期间稳定、可读、允许范围中符合条件的对象，并要求遍历及临时存储无错误完成。Home 不等于所有磁盘。无法读取位置跳过并计数；其他 I/O、名称表示或存储错误标为 Partial，不能冒充完整结果。

范围由最多 8 个根、隐藏开关及最多 32 个排除目录名决定。产品空设置列表及空实际授权范围保持停用；兼容诊断接口的默认 Home 不会替代产品授权。新配置默认不包含隐藏文件，已有配置保留原值。不读取 gitignore，也不默认排除 node_modules、build、target、Library 或应用包。

macOS 授权搜索中，能解析且真实目标位于授权根内的符号链接可作为条目列出，但不递归其目录目标；损坏或越界链接跳过。不同路径的硬链接分别保留。内部查询临时目录排除。执行时重新校验路径、类型和链接目标，稳定行不等于跳过执行验证。

## 授权

macOS Host 在启动和保存搜索设置时恢复只读书签，持有搜索所需的访问租约。文件夹选择只验证草稿的书签，验证结束立即释放临时租约。书签文件保留已保存根目录所需的记录，保存设置后才启用新范围。取消选择、放弃草稿或验证失败时，搜索继续使用已保存的范围。

目录授权与偏好保存串行处理。返回结果必须对应本次设置操作，且根目录输入未被修改，才会更新草稿。启动时无法恢复已保存的授权则停用文件搜索，空 roots 不回退 Home。完全磁盘访问需要在系统设置开启，文件夹选择不会保证所有后代始终可读。

Windows 使用设置中的根目录白名单和当前用户文件系统权限。目录选择与保存决定
搜索范围；目标仍由 Core 按冻结范围复核。

## 查询流水线

```text
输入 / 类型 / 范围版本
   ├─ 配置的有界快批 → 核验并显示早期候选
   └─ 输入稳定后完整遍历 → 查询临时记录
                              → 外部排序 / 未读尾部归并
                              → 按 cursor 读取下一批并追加
```

macOS 上，Spotlight 返回多少、是否失败都不决定是否遍历（少于 2 个字符的短查询跳过 Spotlight 快批，直接由完整遍历覆盖）。
Settings → Search 允许在默认 `SystemIndex`、`Ripgrep` 与并发合并的
`Combined` 之间切换快批引擎。快批调用使用本次查询冻结的配置。Ripgrep 或 Combined 需要
应用可找到 `rg` 才能使用该快批分支。快批为空或不可用时仍会完整遍历。

Windows Combined 先尝试 Everything，通过本地 IPC 查询冻结根目录和转义后的字面名称。
若无结果或不可用，则尝试系统 Windows Search 与可用的 Ripgrep。Core 先复核各引擎候选
的实际路径、文件类型、匹配条件、隐藏和排除规则，再发布快批。完整遍历负责最终结果，
并补齐索引缺失、超过候选上限及非字面匹配。显式路径沿用范围校验与直接目录浏览。

| 模块 | 职责 |
|---|---|
| `features/filesystem/search.rs` | 快批 / 扫描协调、系统能力、Candidate 与动作绑定 |

## 资源与生命周期

遍历器一次读取一个目录，把待遍历目录写入磁盘 FIFO；不在内存收集全树，不为每项创建任务。必要属性以外不读正文、图标或项目数据。

命中写入权威二进制记录（原始路径、类型、分数和归一化名称），flush 后推进可读边界。归并和分页复用记录中的匹配数据。目录队列只在读端追上尚未提交的尾部时 flush。`ScanScope` 固定本次查询的范围 / 隐藏 / 排除和显式路径选项；链接的真实目标仍在索引核验和遍历时重新读取，不缓存为永久授权。外部排序通过 `committed_boundary()` 获取已提交记录上限，不直接访问进度内部字段。内部每批 64 项；排序段最多 512 项 / 1 MiB，最多 16 路归并。新增命中仅与未读尾部合并，已经展示的路径去重；失败重建从权威记录恢复，不因推进游标漏项。每个查询的队列、命中及排序文件共用 512 MiB 写入预算；释放失效排序段时归还预算，超限标记 Partial。原 JSON 双向游标已移除，next_cursor 仅表示本查询仍可追加，执行资格由 Rust 来源句柄保管。
并发分页按读取游标、追加并发布快照的顺序串行完成。后一请求使用前一请求已经发布的展示路径。

查询、类型、范围、来源目录或会话变更撤销旧任务。worker 持有 admission 至真正结束；有界通道避免积压。临时目录使用私有权限和 lease 锁，释放引用后清理，异常退出的无活租约目录在后续准备时回收。

自动发布的结果头部最多 64 项。主动加载时从查询临时记录读取下一批并追加到当前
Session，已交付路径用于去重，供连续滚动和对象执行使用。随着加载批次增加，已交付
候选及其投影的内存也可能增加。独立窗口投影测量与当前 App 的加载趋势分别记录，
见[性能指南](performance.md)。完整遍历是否完成由扫描进度与资源状态决定。

## 临时目录与回收站过滤

普通文件名搜索默认不遍历系统临时目录，以及 macOS `~/Library/Caches/<app>.ShipIt/` 更新器缓存、`~/.Trash/` 和 `~/Library/CloudStorage/<provider>/.Trash/` 回收站；Spotlight 快速候选也执行同一过滤，避免被排除的内容重新出现在列表中。系统临时路径由平台层发现，每次查询准备一次，过滤本身不增加逐条 IO。

不会只因名字是 `tmp` / `temp` 而排除项目目录，也不排除整片 `Library/Caches`、`.cache`、`.m2` 或 `node_modules`。这使仍有使用价值的配置文件保持可搜索。

不会排除 OneDrive 等云盘的普通文件夹，或项目内部同名 `.Trash` 文件夹；同名普通文件也保留。普通云盘目录的真实读取超时仍报告部分结果。

直接输入这些目录地址，或把其中的具体目录配置为搜索根，是明确搜索该目录的意图，仍可搜索；原有授权范围检查和用户设置的排除规则继续适用。默认搜索的完整性指上述规则界定的范围，不包括主动排除的临时目录与回收站。

## 部分结果与诊断

文件数量、扫描进度及重试入口显示在类型筛选下方；文件页没有通用页脚。打开与更多操作入口随当前选中项显示在行右侧，`Enter` / `⌘K` 的逻辑保持不变。

无权限的子目录单独计数并跳过，不在查询期间申请权限。扫描时已经消失的子项安静跳过；用户配置的根目录消失仍属于可处理的范围异常。其他扫描异常保留已找到结果，并在状态栏显示部分结果与实际问题数量及重试入口。最多 8 条具体原因通过 tracing 写入主程序 stderr；设置 `RUST_LOG=anywhere_core=debug` 可查看，且不记录查询正文。配置根目录被移除、无法表示的文件名、读写失败等不能统一归因于权限不足；重试会重新扫描当前范围。

## 系统预览

系统预览已移除旧 64 KiB 文本读取、传统编码猜测和固定分栏。Rust 继续校验候选、版本和文件权限，只将经校验的原文件交给平台预览器。macOS 使用系统 Quick Look，Windows 使用当前用户运行的外部 QuickLook。详细操作、资源和验收边界见 [系统预览](native-preview.md)。

## 验证边界

回归覆盖重叠根、隐藏目录、gitignore、类型后过滤不漏项、Unicode / 标点 / 拼音、显式路径、链接与权限边界、临时存储失败、取消、稳定前缀、对象执行以及连续加载 / 系统预览返回。最新工程状态见 [GPUI 技术方案与验收](mvp-gpui.md)。

历史性能 / GUI 证据保存在 [V0.7 收尾](archive/v0.7-closeout.md)，不能当作后来构建的同机测量。库选型和 Quick Look 调研见 [研究资料](research/README.md)。

Spotlight 快批使用进程内 MDQuery，以一次 search scope 数组提交全部已授权根，并保留超时、取消、输出上限和规范化后的根范围核验。Combined 快批并行执行 Spotlight 与 Ripgrep，再对可用结果合并去重。
