# V0.4 Context 来源验收记录

状态：2026-09-28，`dev-0.4` 开发中。自动化检查通过；以下真实应用交互尚未验收。

## 已实现的开发切片

- 唤醒时冻结前台应用身份，再异步采集 Finder 选中项、选中文本、Safari/Chrome/Edge 当前 URL 和一次剪贴板文本快照。来源独立运行，不占用首屏 Context 图预算；来源的值以各自实际读取时为准，不能保证是热键按下瞬间的内容。
- 捕获结果按来源、所属应用、时间和状态进入 Session；输入变化后沿用本次唤醒的快照。迟到结果通过 Session、Revision 和来源设置代次校验。
- Finder 多选保留集合对象，最多展开 8 个子项进入 Context 图；整组选项提供“Copy Selected Paths as JSON”，避免每个文件重复一组打开动作。Finder 原生读取最多接受 32 个选中项。
- 识别出的 URL、JSON、目录和 Git Context 沿用采集来源，进入现有 Action、Scope 和 Ranking。剪贴板来源的原文及推导值不在 Context 摘要或动作副标题中展示；超过 16 KiB 的文本不进入 Context 或 Session Facts。采集错误和授权状态不记录原文、路径或 URL。
- 设置中四种来源可单独关闭，配置写入现有 `settings.json`；旧配置保持来源默认开启。关闭后不再发起对应的系统读取。
- 浏览器当前页支持 Safari、Chrome、Edge 最前窗口的当前标签页，且只接收 HTTP(S) URL；其他浏览器暂不在本版承诺范围内。

## 真实应用验收矩阵

| 场景 | 预期 |
|---|---|
| Finder 选中单文件、单目录、多文件 | 相应 Context 与动作出现；多选只显示整组文件动作；特殊字符文件名保持完整 |
| Finder 未选中、Automation 拒绝、Finder 退出重开 | 空选区不报错；拒绝和进程失效不生成虚假 Context；应用搜索仍可用 |
| TextEdit / 编辑器中选中 URL、JSON、普通文本 | 产生 Selected Text Context；可识别对象复用现有动作；输入后不重复读取系统选区 |
| Accessibility 拒绝、控件不支持、长文本 | 状态明确；其他来源和应用搜索继续工作；超长文本不作为截断对象执行 |
| Safari、Chrome、Edge 切换标签和窗口后唤醒 | 冻结唤醒时的浏览器实例，读取执行时该实例最前窗口的活动标签页 URL；期间页面导航可能改变结果，输入后保持已采集的快照 |
| Safari、Chrome、Edge 无窗口、非网页地址、Automation 拒绝、退出重开 | 不猜测 URL、不把旧页带入新 Session；其他功能继续工作 |
| 剪贴板为文本、非文本、长文本、拒绝访问 | 每次唤醒只读一次；可识别文本生成 Context；空或失败不阻塞历史与 Git 状态 |
| 分别关闭四个来源后重启应用 | 设置仍在；关闭的来源不读取系统数据；手动输入 URL/路径仍可用 |
| 快速连续唤醒、输入、关闭 | 迟到来源只进入原 Session 的当前 Revision，不覆盖新 Session 或已关闭窗口 |
