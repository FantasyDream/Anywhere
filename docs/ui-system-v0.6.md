# V0.6 UI 系统梳理

日期：2026-10-08。当前开发版本：0.6.0+19；全页面统一始于 0.6.0+10。

## 目标与范围

统一当前所有页面：Launcher（普通搜索、捕获内容、Scope、菜单浏览、结果预览）、Settings 五个分类、动作/Context 快捷键表单与规则/应用选择弹窗、Running Tasks 的列表/详情/输出、提示与启动失败页。

本轮保留已有 Context、Scope、15 秒剪贴板、Esc 顺序、执行和快捷键规则。页面重组只涉及设置分类导航；未保存的隐藏应用草稿跨分类保留，关闭/退出仍执行原有保存保护。

## 视觉系统

| 层级或组件 | 统一规则 |
|---|---|
| 原生窗口 | `WindowMaterial` 创建 AppKit 背景模糊，深色材质，保留系统交通灯和窗口生命周期 |
| 窗口内容 | 深色半透明外壳；内容卡片、输入与输出使用稳定底色，减少背景对文字的干扰 |
| 主要操作 | 蓝色实色按钮：Run、保存、完成；禁用状态通过主题反馈 |
| 次要操作 | 有边框的圆角按钮：录制、编辑、添加、重载；辅助返回/说明使用文本按钮 |
| 输入与选择 | 输入框使用凹入底色、边框、焦点描边；搜索有图标。选中列表项使用蓝色底色与浅色文字；分类导航使用中性灰选中态 |
| 状态 | 文字加图标；运行蓝、完成绿、失败红、警告黄。不会只依赖颜色 |
| 快捷键 | 统一 keycap，与普通状态标签区分；可编辑的键位置于带编辑图标的按钮内 |
| 提示与空状态 | 统一 `AppNotice`、`AppEmptyState`，字号、图标、边框与间距一致 |
| 表单/弹窗 | 共享主题；表单边框和主次按钮保持一致，继承原来的录制/校验/取消流程 |
| 字体 | 系统字体；命令、路径与输出的代码内容保留等宽字体 |

参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 对材质与内容层级的指导。当前 Flutter 自绘控件不等同于原生 Liquid Glass 控件；本轮统一现有 AppKit 模糊与 Flutter 内容层，没有宣称实现系统折射效果。

## 页面调整

- Settings 使用固定分类导航：General、Shortcuts、Context、Search、Plugins；长内容在当前分类独立滚动。切换分类取消正在进行的唤醒键录制，保留未应用的草稿。导航支持键盘焦点并标明选中状态。
- Launcher 的搜索/内容输入图标、Scope、候选选中态和 keycap 使用统一色板；Run 与普通返回操作有明确层级。
- Running Tasks 使用同一窗口材质、稳定的侧栏和输出底色；运行/完成/失败状态有图标与文字。窄窗口或大字体下将输出跟随操作收为带提示的图标按钮，底部帮助分行，状态行允许换行且提供足够行高。
- 快捷键编辑、规则选择、应用选择弹窗统一背景、输入边框与按钮；应用列表有类型图标。选定动作后的表单随内容收紧并支持滚动，不再保留列表高度；空规则提供说明与添加入口。
- 启动失败使用同一主题与可滚动、可选择的错误详情。

## 实现边界

共享 UI 放在 `apps/flutter/lib/ui/`：`AppStyle` 负责主题与语义颜色；`app_components.dart` 提供卡片、图标、标题、提示、状态、空状态、keycap、工具栏、侧栏项与失败页；`AppIcons` 统一语义图标。Settings 与 Execution 不再依赖 Launcher 的样式文件或候选行来渲染通用控件。Host 的 `WindowMaterial.swift` 统一原生材质创建。

继续使用 Impeller。AppKit 原生材质负责系统材质偏好的响应；本轮不新增动画或模糊渲染层，也不声称完成所有系统辅助功能设置及读屏组合的验收。

## 设置页重构（0.6.0+11）

截图反馈暴露了两个实际问题：`SwitchListTile` 的整行悬停着色将标题/开关与下方状态切成两种背景；adaptive 开关使用移动端尺寸。设置页改用 `SettingsToggleRow` 与 `SettingsToggle`，同一行在统一卡片背景内呈现图标、标题、说明、状态和开关，反馈只落在可操作控件上。

- 设置窗口使用稳定深色底色，缩小页头与分类导航，删除装饰性大图标和副标题。Done 是关闭入口，使用紧凑次要按钮；保存仍是主要按钮。
- 设置页与其弹窗共用 `SettingsStyle`，从共享 AppStyle 继承色板与形状，覆盖桌面控件尺寸。常规按钮高度约 24–28 logical px；开关轨道 30×18，点击区域最大 40×30，支持 Tab、Space/Enter 和开关状态语义。
- 所有来源行的状态与正文共用背景；原来 51×31 的 Cupertino 开关不再直接用于设置。不会通过缩放命中区域来缩小控件。
- 快捷键添加按钮按内容宽度排列、必要时换行；编辑键位移除按钮中的第二层 keycap 底色。减少重复帮助段落。
- 搜索输入保留凹入底色，悬停不改变整个输入背景；保存按钮与输入留出间距。空插件状态与重载按钮在同一行。
- 表单使用同一套紧凑开关、按钮与带边框选择框。Context 弹窗高度随文字大小适配，底部操作允许换行。
- 实机核对设置五个分类、行内背景、动作/Context 编辑及规则选择。最终开关语义单独成节点，不将周围表单误读成一个开关；检查草稿已全部取消。开发包 `0.6.0+11` 的 Release 构建、固定签名和归档校验通过。
- 本轮前端分析及 113 项 Flutter 测试通过，包含新开关点击、键盘、禁用、语义和大字体弹窗，以及原有草稿/保存/关闭回归。未修改业务采集、Scope、快捷键注册或执行路径；没有重新运行 Rust 全套测试。

## macOS 视觉调整（0.6.0+12）

以 Apple 的 [macOS 设计指导](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/)、[工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars) 和 [侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars) 为参考，统一深色外观的颜色、排版、图标与布局：

- 深灰窗口、略亮的分组、凹入输入框、轻分隔线，减少蓝灰叠色。蓝色用于主要操作和内容列表选中；设置分类用灰色选中背景，小色块图标帮助识别分类。
- 设置改为完整高度的侧栏与右侧工具栏，保留系统交通灯；分类标题替代大号通用 Settings 标题。任务页复用 `AppToolbar`，分类复用 `AppSidebarItem`。
- 全页面统一 Cupertino 图标字体：单线语义图标，保留应用本身的图标。删除图标外围重复底板，减少列表描边和额外选中竖线。它们是 Flutter 的 Cupertino glyph，不是运行时原生 SF Symbols。
- 常规正文 13、说明 11、局部标题 15 logical px，系统字体、常规字重。按钮约 26 px，圆角 5；卡片圆角 10，列表选中圆角 6。窗口边框、卡片和按钮有不同层次，不把每个元素都做成大胶囊。
- 下拉/搜索/录制/保存/状态提示共用主题；表单名称放在输入框上方，避免浮动标签和凹入输入混杂。状态始终保留图标与文字。任务选中项的目录、状态和退出码改为浅色，保证蓝底下可读。
- 原生模糊背景改用 `NSVisualEffectView.Material.underWindowBackground`，保留 Impeller。当前为固定深色 Flutter UI + AppKit 背景，并未实现系统浅色模式、动态强调色或原生 Liquid Glass 控件。

关闭保护触发的提示会在设置列表前插入内容。为快捷键编辑组件保留稳定 key，避免列表位置变化时销毁编辑所有者，导致关闭弹窗后保存结果丢失；原有创建/编辑/删除及关闭保护测试覆盖该回归。Scope、Context、15 秒剪贴板和 Esc 顺序保持原契约。

## 原生 Liquid Glass 与按钮调整（0.6.0+13）

用户截图中窗口被深色 Flutter 底层覆盖，列表选中蓝色与 Run 按钮过强。本轮改为：

- `WindowMaterial` 在 macOS 26+、支持相关 API 的 SDK 下使用公开 `NSGlassEffectView`（regular）；Flutter view 是其 `contentView`。遵循 Apple 的 [contentView 契约](https://developer.apple.com/documentation/appkit/nsglasseffectview/contentview)，不把玻璃视图作为内容后方的兄弟视图。旧系统/旧编译器用 `NSVisualEffectView` 的 behind-window HUD 材质回退。
- `WindowMaterialController` 持有原来的 Flutter controller，作为窗口根控制器。Launcher/Settings 移动同一个 host，保持一个主引擎；任务窗口仍有按需创建/关闭的引擎。保留原 first responder、系统交通灯、隐藏时缩小窗口的行为。没有增加 Flutter 模糊滤镜或换掉 Impeller。
- Launcher/设置/任务的外壳改为低不透明度深色遮罩；卡片、输入框与输出保持更高遮盖度以帮助阅读，弹窗/菜单使用独立高遮盖度底色。原生材质由 AppKit 处理，按钮仍为 Flutter 控件，不能把它们宣称成原生玻璃按钮。
- 常规按钮最小高度 24 logical px，文字 11；图标按钮 26。Run 使用淡蓝半透明底色与轻边框，保存使用较柔和的蓝色。选中行从纯蓝实色改为蓝灰半透明色；候选行高度从 52 调为 48，滚动定位和窗口高度使用同一行高。
- Scope、Context、15 秒剪贴板、Esc、录制/保存及执行逻辑沿用原契约。

前端分析与 114 项 Flutter 测试通过。原生 Host 检查增加玻璃 contentView 所有权、旧材质回退、角半径、窗口间移动和缩放后的内容几何回归，全部通过。Release 构建和固定签名通过；0.6.0+13 的 App/ZIP 归档一致及 SHA-256 校验通过。版本已对齐 Rust 0.6.0-dev.13。

## 明亮背景下的可读性（0.6.0+15）

本节为历史方案。用户要求背景保持原样，整窗 tint 已在 build 16 撤销，以下背景调整不再代表当前实现。

用户提供的白色页面截图显示，完全透明的内容根层使次要文字、Scope 和淡蓝选中态接近背景。本轮在所有窗口的共享 AppStyle.windowBuilder 加入统一深色半透明 tint；无背景能力或减少透明度时使用同色不透明底色。系统玻璃、模糊和现有引擎保留，不增加 Flutter 模糊滤镜。

次要/提示文字调整为更明亮的中性色；候选副标题使用 secondary。选中行使用深蓝半透明底色与细边框，Scope 有可辨认的控件边界，快捷键使用深色底色与描边，Run 使用有对比度的蓝色。控件大小、Scope、Context、执行和 Esc 逻辑不变。

新增对比度回归覆盖白/黑/红/蓝底图上的普通与选中小字号文字，要求至少 4.5:1。Flutter analyze 与 130 项回归通过；用 Flutter 离屏渲染核对明亮底图的正文/副标题/选中态，不将其计作 AppKit 实机玻璃验收。arm64 Release App/ZIP 构建、固定签名与归档校验通过；真实桌面观感由用户启动新版确认。

新产物独立输出为 `build/Anywhere-dev-0.6-build15.app` 和 `build/Anywhere-dev-0.6-build15-macos-arm64.zip`，当前运行的 build 14 未被覆盖。


## 保留原玻璃背景，仅增强元素（0.6.0+16）

按用户反馈撤销整窗深色 tint。有原生材质时 AppStyle.windowBuilder 回到透明；无材质或减少透明度时回到原先的 `#24262b`。Launcher/设置/任务原有表面色、透明度与 WindowMaterial 实现保持原样。

元素自身增强：主文字纯白，副文字更亮；候选标题 semibold、副标题 medium，轻微文字阴影勾勒轮廓。默认动作图标提供局部深色图标底座；Scope/快捷键使用局部深色底色和细边框；选中行与执行按钮使用有独立对比度的蓝色。按钮和列表主要尺寸、Scope、Context 与键盘逻辑沿用原契约。

控件文字的 4.5:1 回归针对控件自身底色，不把它描述成任意玻璃背景上所有文字均达到该对比度。平台回归同时验证原透明根层及原不透明 fallback。Flutter analyze 与 130 项回归通过；实际玻璃观感仍待用户打开新版确认。

Release App 与 ZIP 已单独输出为 `build/Anywhere-dev-0.6-build16.app` 和 `build/Anywhere-dev-0.6-build16-macos-arm64.zip`，签名及归档校验通过。
