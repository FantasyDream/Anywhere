## 功能核对

| 能力 | 当前实现与证据 |
|---|---|
| 普通 File Search Action | Global 输入中英文标题 / 别名可找到；入口不常驻空白首页，沿用 Action 快捷键机制 |
| 共用 Launcher | 搜索栏、类型栏、结果行、Actions、Preview 与根窗口组件 / 返回契约复用 |
| 查询与覆盖 | Spotlight 提前候选 + Rust 完整遍历；隐藏、未索引项、文件与目录；明确允许根 / 排除设置，无长期索引或 rg 依赖 |
| 连续结果 | 内部 64 条批次按需追加；没有页码 / 翻页 / 刷新操作；保留滚动、选择与旧结果执行目标 |
| 生命周期 | 防抖、取消、Session / Revision / 配置 guards；返回或清空查询释放临时记录；错误以 Partial 反馈 |
| 文件操作 | Open、Copy Path、Reveal、目录 Terminal；目标独立绑定与执行复验，成功复用 Usage |
| 文本预览 | 单 worker、64 KiB、迟到响应拒收；未实现图片 / PDF 渲染 |
| 设置 | 来源开关、隐藏开关、根 / 排除草稿与保存，保留旧配置；保存竞态和关闭决策有回归 |

上述实现 / 自动化证据见 [MVP](mvp-v0.7.md)、[V2](../file-search.md) 与本轮检查日志。build 14 的文件打开 / Copy Path 实机记录见 [原验证记录](validation-v0.7-build14.md)；本轮 build 15 新验证范围见下方，不把历史操作全部列为本轮重测。
