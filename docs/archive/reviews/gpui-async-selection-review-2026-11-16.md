## 自动化

定向回归共 12 项，覆盖：

1. History / Shelf 首次读取纳入查询代次；新查询先回、旧查询后回仍保留新列表。
2. 查询和复制回包在返回父页或隐藏后不能覆盖提示。
3. 文件预览关闭、改选、revision 更新、换页、Session 更新和同目标新请求后，
   旧资源 / 旧错误均被拒绝；Clipboard 同样绑定条目 ID。
4. 系统面板关闭撤销等待中的更新；已准备但尚未执行原生 show 的请求也能取消。
5. 新预览准备失败保留原面板监视代次。
6. Shelf 在真实测试 viewport 中按 ⌘↓ 显示末项，⌘↑ 回到首项，并清理旧复制反馈。
7. 应用历史空来源、会话 / 查询通道中断的加载收尾，以及 fallback 菜单二次关闭。

测试使用可控 channel 排序与独立临时数据目录。预览测试拒绝过期资源或模拟关闭
通知，不展示原生面板；它们不能证明真实 Quick Look、IME 或焦点已经通过。

最终门禁全部通过：`scripts/check-gpui.sh` 为 218 项 GPUI 测试通过，
`scripts/check.sh` 的完整工作区 Rust 测试为 901 passed / 6 ignored / 0 failed，
并通过严格 Clippy、生成物、文档、SDK / 示例和架构检查。
初次受限环境中的 macOS 菜单探针无法取得 Finder，解除沙箱限制后完整重跑通过；
这只证明原生菜单探针通过，不表示完成本页的物理窗口验收。
交付证据入口见 [本轮 MVP 证据](../v0.14-gpui-development-records.md#2026-11-16-异步与选择审查修复)。
