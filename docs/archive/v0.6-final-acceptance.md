## 功能核对

| 要求 | 实现与验证 |
|---|---|
| Launcher 内自定义键 | 固定动作与意图共享配置，按当前完整 Context 解析，不受搜索词/Scope 限制；文本预览、输入法组合和执行期间有门禁 |
| 全局键 | Carbon 注册；隐藏时重新捕获源应用与 Context，等待完整图，取消或超时不执行 |
| Context 意图 | 显式应用/类型条件；条件更具体优先，同等匹配要求选择，匹配动作失效不回退另一命令 |
| 多对象 | 展示精确候选供选择；不按 Ranking 猜测对象；Esc 取消 |
| 身份与安全 | 保存业务动作身份与条件；不保存捕获路径、URL、Candidate、Session 或执行凭证；菜单持久绑定仍拒绝 |
| 录制 | 三个设置入口共用原生录制；无效键继续录制，重复/取消/失焦/关闭与迟到回复受控；已注册的唤醒键也进入录制 |
| 冲突与恢复 | 保存失败恢复原绑定及支持状态；设置关闭恢复失败时留在原页并释放部分注册，可重试；冲突不阻止退出 |
| 配置迁移 | v1 保持 local，v2 保留 global，v3 保留意图规则，统一迁移为平台无关键码 v4；未知未来版本拒绝覆写 |
| 插件生命周期 | 撤销释放键位但保留配置；恢复重新注册；动态脚本离开项目不等于撤销 |
| 使用记录与后台任务 | 沿原业务动作执行与 Usage 路径；进程动作进入既有 ExecutionSession 与 Running Tasks |
| 项目外编辑 | 使用已保存动作元数据修改组合键/global，保持动作 ID；Core 仍决定注册资格与当前执行目标 |

导入/导出按当前 [路线图](../roadmap.md) 延期，不属于这次 MVP；近期验收以 macOS 为主。不同布局的显示标签与 Windows 支持没有被声明为已验收。

## 仍需实机验收

1. 从其他应用使用真实键盘触发固定动作；确认本次 Context、执行结果与 Usage。
2. 同一意图在 Finder/浏览器切换条件；多对象或同等匹配时选择，Esc 取消。
3. 缺少来源/权限、动作不可用与慢采集时拒绝执行；不会选择低优先级替代动作。
4. 多次触发、编辑期间触发、退出取消/正常退出及重启恢复配置。

自动化输入曾无法激活 Carbon 热键，对照原有唤醒键同样无事件；因此不能把模拟按键结果算作上述验收，也不能把注册成功当作真实触发成功。

通过这些场景后更新本记录与 MVP 状态，再决定正式发布。
