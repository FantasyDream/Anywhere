# Clipboard 多格式改造

2026-10-16，基于 `clipboard-rs 0.3.5`，延续 V0.10。

1. 平台：剪贴板格式读写与变化监听使用 clipboard-rs；保留 macOS 权限与读取大小检查的薄适配。一次变更读取全部可持久化表示，并复验代数。临时 / 隐藏 / 自动生成标记不持久化。
2. 模型与存储：一次复制为一个 Payload，包含多个格式；纯文本、HTML、RTF、图片、文件列表和可序列化自定义格式。独立 SQLite BLOB 表、摘要检索、内容指纹去重，事务完成插入与淘汰；迁移旧纯文本记录并保留 ID 与暂停设置。
3. 展示：共享工具页，按内容类型显示图标；固定右侧展示文字、图片缩略图、文件路径和格式信息；未知二进制仅展示元数据。恢复保留原格式，文件列表在复制前校验路径，缺失时明确失败。
4. 验证：先代码与单元测试 / 原生检查 / 架构门禁，再重新构建和界面测试。

## 边界

- 每条最多 16 MiB、64 个格式；总保存 128 MiB 或 1,000 条，先达到者淘汰最旧记录。列表仅摘要，单条预览最多 64 KiB 文本和 512 像素缩略图。
- 文件历史保存引用，不备份文件；恢复不触发移动或删除。
- 同一格式在多个 pasteboard item 中的任意组合、文件承诺 / 延迟对象和应用内部指针不能由 clipboard-rs 通用序列化，不宣称这些对象可以完整恢复。
- 不取消既有权限、安全过滤、默认关闭及暂停期间不补录规则；采集不隐式开启。
