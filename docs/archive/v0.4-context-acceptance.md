# V0.4 Context 来源验收记录

> 历史记录：仅描述文中日期与构建，不作为当前使用或实现契约。当前入口见 [文档导航](../README.md)。

状态：2026-10-01，`dev-0.4` 工程收尾完成，候选版本 `0.4.0+3`。自动化与签名构建已验证；完整真实应用与权限矩阵尚未验收，因此不标记为正式发布。

## 已实现的开发切片

- 唤醒时冻结前台应用身份，再异步采集 Finder 选中项、选中文本、Safari/Chrome/Edge 当前 URL 和一次剪贴板文本快照。来源独立运行，不占用首屏 Context 图预算；来源的值以各自实际读取时为准，不能保证是热键按下瞬间的内容。
- 捕获结果按来源、所属应用、时间和状态进入 Session；输入变化后沿用本次唤醒的快照。迟到结果通过 Session、Revision 和来源设置代次校验。
- Finder 多选保留集合对象，最多展开 8 个子项进入 Context 图；整组选项提供“Copy Selected Paths as JSON”，避免每个文件重复一组打开动作。Finder 原生读取最多接受 32 个选中项。
- 识别出的 URL、JSON、目录和 Git Context 沿用采集来源，进入现有 Action、Scope 和 Ranking。剪贴板来源的原文及推导值不在 Context 摘要或动作副标题中展示；超过 16 KiB 的文本不进入 Context 或 Session Facts。采集错误和授权状态不记录原文、路径或 URL。
- 设置中四种来源可单独关闭，配置写入现有 `settings.json`；旧配置保持来源默认开启。关闭后不再发起对应的系统读取。
- 浏览器当前页支持 Safari、Chrome、Edge 最前窗口的当前标签页，且只接收 HTTP(S) URL；其他浏览器暂不在本版承诺范围内。

## 2026-10-01 收尾优化

- 四种来源统一采用类型化错误及协议状态，区分空内容、权限拒绝、不支持、应用实例变化、超时、内容超限、选中项超限、不可用和读取失败。不通过错误字符串推断权限。
- Launcher 对可恢复的问题给出简短提示；空选区、不支持和应用退出等状态留在 Settings → Context Sources。多来源失败时提示优先级固定，不随异步返回顺序跳动；设置中可查看每个来源上次唤醒的状态。
- 权限拒绝提供 Open Settings，辅助功能/Automation 使用系统设置入口，剪贴板打开系统设置主应用。打开失败保留当前动作并给出说明；打开成功关闭 Launcher，处理授权后再次唤醒重采集。程序不会自动更改权限。
- 剪贴板已知被设为始终拒绝时明确报告权限拒绝；其他无法确定原因的读取失败报告不可用，不猜测授权。macOS 15.4 以下仍保留原读取方式，不调用新属性。剪贴板与选中文本统一限制为 16 KiB UTF-8，超限返回 TooLarge，不生成截断 Context 或 Fact；中文和 emoji 按字节边界处理。
- Finder 目录和选区共用有界系统读取；捕获的实例在读取前后复验，错误不携带 AppleScript 原始诊断或路径。
- Copy URL、Copy Path 和 Copy Selected Paths as JSON 共用重复内容隐藏规则。相同 URL 规范化后合并；不同打开目标保留来源标注与独立执行参数。隐藏动作不会重新进入搜索、Scope 或完整 Action Offer。
- Launcher 关闭后只保留来源/状态/时间供设置页查看，清除旧 Context 正文。设置关闭来源后掩盖旧错误提示，下次唤醒不读取该来源。
- 设置卡片使用 Material 背景与圆角裁剪，修复开关/列表项点击反馈被装饰层遮挡的问题。
- Rust workspace、Flutter 和 macOS 包版本统一为 `0.4.0`，构建号 `3`；签名身份和 Bundle ID 保持现有本机发行身份。

## 真实应用验收矩阵

| 场景 | 预期 | 本候选构建实机结果 |
|---|---|---|
| Finder 选中单文件、单目录、多文件 | Context 与动作出现；多选只有整组文件动作；特殊文件名完整 | 待验收 |
| Finder 未选中、Automation 拒绝、退出重开 | 空选区不报错；拒绝/实例失效不生成虚假 Context；应用搜索可用 | 待验收 |
| TextEdit / 编辑器选中 URL、JSON、普通文本 | 产生 Selected Text；识别对象复用动作；输入后不重复读选区 | 待验收 |
| Accessibility 拒绝、控件不支持、长文本 | 状态明确；其他来源继续工作；超限不执行截断对象 | 待验收 |
| Safari、Chrome、Edge 切标签/窗口后唤醒 | 读取捕获实例最前窗口当前页；输入后保持快照；来源明确 | 待验收 |
| 三种浏览器无窗口、非网页地址、拒绝授权、退出重开 | 不猜 URL，不带入旧页面；其他功能继续工作 | 待验收 |
| 剪贴板文本、非文本、长文本、拒绝访问 | 一次唤醒只读一次；空/失败不阻塞历史与 Git；重复复制隐藏 | 待验收 |
| 关闭四种来源并重启 | 设置保持；关闭的来源不读取；手动输入仍可用 | 待验收 |
| 快速连续唤醒、输入、关闭 | 迟到数据不覆盖新 Session、旧 Query 或已关闭窗口 | 待验收 |
| 设置页状态与 Open Settings | 状态对应上次唤醒；打开系统设置；授权后再唤醒恢复 | 待验收 |
| 安装/升级与物理快捷键 | 两种入口、键盘返回及固定签名授权行为正常 | 待验收 |

已有用户实际使用反馈不等于本候选构建的完整验收。每项应记录应用与系统版本、通过/失败/不支持、复现步骤。这里不自动撤销系统授权或替用户填写通过。

## 已运行的自动化检查

- `scripts/check.sh`：225 项 Rust 测试、46 项 Flutter 测试、Clippy、Flutter 分析、架构检查及原生菜单/选中文本/剪贴板检查。
- 原生合成用例覆盖 16 KiB 与 emoji 边界、超限不返回正文、已知剪贴板拒绝不发起读取，以及询问过程中策略变为拒绝。使用模拟剪贴板，不覆盖用户剪贴板。
- 公共状态枚举变化已运行 `scripts/generate-bridge.sh` 并编译 bridge crate；协议保留旧状态值和旧快照缺失字段的兼容行为。
- `scripts/build-macos.sh`：arm64 Release Flutter/Rust/Swift 构建、固定本机签名与签名校验，生成 `build/Anywhere.app`。另行打包 `build/Anywhere-dev-0.4-macos-arm64.zip`，归档完整性与 App 签名校验均通过，包内版本为 `0.4.0`、构建号 `3`。

这些检查不能替代上述实机矩阵、首次授权弹窗、重装授权保留或物理热键验证。完成矩阵并处理发现的问题后再标为正式发布。普通文本新动作、批量打开、更多浏览器和剪贴板历史继续按 roadmap 后续阶段评估。
