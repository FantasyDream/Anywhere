# Launcher 交互契约

当前实现：V0.12 / Build 16；最后核对：2026-10-23。使用教程见 [README](../README.md)，本页是导航、快捷键与状态恢复的统一依据。

## 入口与 Scope

- Current App 默认 `⌘⌥Space`；Global Search 默认 `⌘⌥⇧Space`。搜索图标菜单也可切换两种入口。
- 空白 Global 不常驻 File Search 等工具卡片；输入名称查找普通 Action，或设置 Action 快捷键。
- Current App 聚合当前环境所有可用 Action，包括应用菜单、Folder、Git、Developer 等；其他 Scope 硬过滤原领域 Group，Action 不改写 group_id。
- 当前应用组为 `app.<bundle_id>`，显示实际应用名。无可见动作不生成空 Scope；应用启动候选只属于 Global Search。
- Scope 只改变搜索范围。输入、文件类型和内容来源不成为额外 Scope。只有单一 Current App 时，应用名显示在输入区，省略重复分类栏；范围和键盘逻辑不变。
- Current App 首位；Session 中既有槽位固定，迟到领域追加，消失领域空出槽位。切 Scope 与浏览不计 Usage；菜单不读取 / 写入长期 Usage。

## 推荐、搜索、浏览与对象操作

空查询显示少量推荐，不铺满菜单；可浏览菜单时首页最多显示五条推荐，为 Browse Menus… 留出首屏空间；其他推荐首页仍最多七条。完整菜单与未进入推荐的动作仍可通过浏览、查询和对应 Scope 使用。有查询时搜索整个选定范围，菜单浏览中输入也搜索整个应用；清空查询返回原菜单位置。

文件、收藏目录等对象的 `⌘K` 二级 Actions 绑定当前对象。返回恢复查询、选择和列表位置；旧对象操作响应不能覆盖新目标。输出页面与菜单、对象动作、文件工具共用主窗口风格，不增加独立的通用功能导航栏。

搜索页不显示通用页脚或普通结果条数。选中行右侧显示执行按钮与回车提示，对象支持更多操作时在同一行直接显示 `… ⌘K` 入口，替代主操作的重复回车图标；无更多操作时保留回车提示。原应用菜单的快捷键不展示，用户自定义的 Action 绑定保留。

文件搜索使用同一输入 / 列表，并固定右侧预览；文件数量、扫描进度和重试显示在类型筛选下方。它的类型标签与 Scope 样式及切换键一致，但语义是文件过滤。完整规则见 [文件搜索](file-search.md)。

## 键盘

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 移动候选；文件列表末尾继续加载 |
| `Enter` | 执行或进入当前项 |
| `⌘K`（其他平台页面命令用 Ctrl） | 对象 Actions；可浏览应用菜单时进入菜单 |
| `Tab` / `Shift+Tab` | 向后 / 向前循环可见 Scope；文件页循环类型（兼容 Ctrl+Tab / Ctrl+Shift+Tab） |
| `→` / `←` | 空输入进入 / 返回菜单，有输入保持光标移动 |
| `Esc` | 当前层级返回；根页面最后关闭 |

Tab 仅在搜索框聚焦且分类可用时切换，保留查询与输入焦点；中文组词、导航选择器、对象 Actions、绑定选择或输出层不切换背后的 Scope。Tab 不遍历控件，Web 工具内部的 Tab 仍由页面处理。用户配置的 Action 快捷键独立于原应用菜单快捷键；一个适用对象直接执行，多个对象先选择。快捷键目录和失效规则见 [架构](architecture.md)。

## Esc 与返回

- 导航选择器、对象 Actions、绑定选择、输出等局部层先退出该层。
- 内容输入：清空并回 Current App → 空白 Global → 隐藏。
- 普通查询：先清空；菜单空输入再返回菜单层级；Current App 根再到空白 Global，最后隐藏。
- 文件页：先退出对象 Actions；有查询先清空，再按一次返回父页。返回按钮直接回父页。
- 设置独立窗口通过关闭入口处理保存和草稿，不套用搜索页面的清空规则。

## 隐藏与 15 秒保留

窗口失焦或重复当前唤醒入口隐藏。隐藏即暂停 Session 执行、撤销旧 epoch，预览和排队动作不能因恢复重新获得旧资格。

| 保留的界面 | 15 秒内再次唤醒 |
|---|---|
| 有查询、文件页、菜单 / 二级层、输出或非 Current App 已选 Scope | 恢复原操作和 Context；未完成查询可继续或重发 |
| 空白 Global / Current App 首页 | 按本次入口新建 Session，重新采集前台应用 |
| 明确 Global Action 快捷键、来源 / 扩展设置变化 | 原会话失效，重新捕获所需 Context |

恢复取消旧期限；再次隐藏重新计时。达到 15 秒整体释放临时查询、Context、结果与执行容器。Flutter 展示 Timer 和 Rust 暂停期限各自有版本检查；旧 deadline 不清理新会话或设置草稿。

已经启动的后台任务独立于 Launcher，隐藏与会话清理不停止任务；退出应用结束任务。空白首页新采集规则修复了“复用旧空白 Global、一直不进入 Finder / 其他当前应用”的问题。

## UI 与验收

窗口高度、预览宽度和键盘焦点由 Host 决定；Rust 不传像素布局，也不复制候选 index 作为业务身份。shared UI 与材质见 [UI 设计](ui-design.md)。

回归覆盖内容自填 / Esc、晚到 Scope、对象返回、连续列表、IME、重复 show 后输入连接、失焦 generation、15 秒恢复 / 超时，以及空白首页多应用切换。可控 Backend / Widget 测试不等于真实物理键盘、系统权限或原生玻璃验收。历史现场和验收记录见 [归档](archive/README.md)。
