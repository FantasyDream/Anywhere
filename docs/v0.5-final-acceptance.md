# V0.5 最终功能核对

日期：2026-10-06。分支 `dev-0.5`，App `0.5.0+11`。以当前路线图 V0.5a / V0.5b 和 [MVP 契约](mvp-v0.5.md)为范围。

## 结论

约定的 Developer Actions 和应用运行期间可返回的进程会话均已实现。完整自动化、四组真实工具验收、当前源码 Release 构建与签名/归档校验通过。此前可维护性 Review 的当前问题修复纳入本版；未发现新增阻塞问题。正式发布的安装升级、权限矩阵、读屏、多机器与 Windows 验收仍没有完成；菜单长期身份与 frecency 保持现有安全降级。

| 契约 | 实现入口 | 验证证据 |
|---|---|---|
| 轻量识别 Git / Rust / Maven / Gradle / Node / 显式 Spring Boot | `features/git` 与 `features/developer/provider.rs`，Spring 解析在 `spring.rs` | MVP `project_types_are_additive_and_wrappers_use_the_module_working_directory`、`spring_boot_context_and_run_actions_require_active_local_plugins`；识别仅读本地文件 |
| 常用 Build/Test、Node 声明脚本、Cargo 明确运行目标 | `developer/actions.rs`、`dynamic.rs`、`node.rs`、`rust.rs` | 动态 ID/manager 复验、workspace Check/Test/多个 Run、真实失败退出码回归；无 script/manifest 时隐藏与拒绝旧执行 |
| Context / Scope / Ranking / Usage 复用 | `application/snapshot.rs` 与统一 ActionSearch / execute | `cargo_action_uses_the_graph_scope_history_and_independent_execution_lifetime`，已有 Scope/历史回归；Flutter 自定义脚本与 Cargo Scope 可发现性 |
| 后台运行、返回查看、状态/退出码、Stop、移除完成结果 | `core/execution/mod.rs` 与 Flutter `execution/` | `tests/execution_sessions.rs`；MVP facade 与 Flutter 详情/操作/窗口失败回归 |
