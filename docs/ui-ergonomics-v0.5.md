# V0.5 交互收尾：减少操作负担

版本：macOS 开发 App 0.5.0+8。保留原有 Context、Scope、菜单导航与任务执行契约，主要调整 Flutter 交互和原生窗口衔接。

## 交互原则与落实

| 操作负担 | 本版调整 |
|---|---|
| 从任务窗口回 Launcher 需要找菜单 | 标题栏内提供 Launcher 按钮，支持 ⌘L，打开 Universal Search；后台任务继续运行 |
| 一直依赖鼠标切换任务 | 列表获得焦点时 ↑↓ 切换并保持选中项可见；其他区域可用 ⌘⌥↑↓。日志文本内的箭头与选择操作保留原行为 |
| 多个项目的任务难以区分 | 名称、项目目录名、状态分别展示；保留完整路径提示、文字状态与退出码，避免仅依赖颜色 |
| 历史任务多时难以定位 | ⌘F 查找任务，按动作名或项目路径过滤；Enter 回到列表，Esc 先清除筛选。外部打开具体任务时清除遮挡该任务的旧筛选 |
| 鼠标选择 Scope、进入菜单后不方便继续输入 | 操作完成后恢复 Launcher 搜索输入焦点。保留单击动作执行及 Enter 执行习惯，底部 Run / Open 同样可以点击 |
| 输出持续增加时难以跟上 | 日志跟随末尾；向上滚动后暂停跟随并保留阅读位置，Latest 一次回到末尾继续跟随 |
| 标准输出与诊断混杂，阅读成本高 | Output / Diagnostics 分页，非空诊断有提示。首次打开已失败的任务时默认显示诊断；用户已选择的分页不被后续轮询覆盖 |
| 获取日志需要拖动大量文字 | Copy output 只复制当前分页，并给出 Copied 反馈；更多操作提供 Copy command，按 macOS shell 字面参数引用 |
| 完成瞬间 Stop 原地变成 Remove，可能连点误删 | Stop 与移除位置分离；Remove result 位于更多操作菜单。Return 不会默认停止或移除任务，菜单操作固定绑定打开时的任务 ID |
| 后台刷新很快清掉错误提示 | 操作错误保留到用户关闭或重试；刷新错误成功恢复后消失，失败不清空现有任务 |
| 没有菜单动作时正常搜索仍出现警告 | 成功发现空菜单安静展示；权限不足和发现超时仍保留诊断 |
| 隐藏任务窗口容易与停止混淆 | Esc 隐藏任务窗口，任务继续运行；⌘. 停止当前运行任务。底部提示隐藏和退出的区别 |

这些做法参照 macOS 的常见焦点与键盘惯例，减少重复定位与切换输入设备。[Apple Keyboards](https://developer.apple.com/design/human-interface-guidelines/keyboards)、[Focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)。本版未进行定量人体工学用户研究，不承诺未经测量的效率提升比例。

## 快捷键

| 操作 | 任务窗口 |
|---|---|
| 选择上一个 / 下一个 | 列表焦点下 ↑↓；或 ⌘⌥↑↓ |
| 查找任务 | ⌘F |
| 从查找回列表 | Enter |
| 清除筛选 / 隐藏窗口 | Esc，先清除非空筛选，再隐藏 |
| 停止所选运行任务 | ⌘. |
| 回到 Launcher | ⌘L |
| 刷新任务 | ⌘R |
| 关闭任务窗口（任务继续运行） | ⌘W |

Launcher 的 Scope、菜单二级浏览、Current App 聚合和原有快捷键语义保持不变。

## 验证

- 60 项 Flutter 测试及静态分析通过。新增测试验证筛选与指定任务操作、键盘切换/查找/停止/窗口入口、日志暂停和恢复跟随、失败默认诊断及按当前分页复制。
- 原回归验证最小 760×420 窗口下长标题、路径与命令展开，输出与 Stop 保持可用；错误信息经过自动刷新后仍可读；Scope 点击后搜索框获得焦点。
- macOS 27.0.1 arm64 开发 App 0.5.0+8 构建与持久签名验证通过。实机验证首次打开无鼠标 ⌘F 输入、Esc 清筛选、Enter 回列表、⌘R 刷新、⌘. 停止后窗口保留且服务 PID 结束、⌘L 返回 Launcher 后直接输入。修正了首次键盘焦点和 AppKit 将 ⌘. 当作取消操作的问题。
- Rust 空菜单回归通过。读屏支持、多平台与完整安装升级验收仍以 V0.5 MVP 的限制为准；快捷键的不同键盘布局未逐一验收。停止快捷键使用 macOS 的 period 键码，避免系统提前将字符转换成 Escape。
