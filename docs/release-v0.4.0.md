# Anywhere 0.4.0 · 构建 3

日期：2026-10-01。macOS arm64 本机候选构建；工程检查已完成，正式发布仍待真实应用与权限矩阵验收。

## 新能力

- Finder 选中文件/目录、选中文本、Safari/Chrome/Edge 当前页和单次剪贴板快照进入统一 Context、Action、Scope 与排序流程。
- Current App 搜索当前环境全部动作；Folder / Git / Web 等入口筛选对应领域。首页保持少量推荐，菜单通过 Browse Menus 浏览或直接搜索。
- 四种来源可独立关闭；设置保存并在下次唤醒生效。设置页显示上次采集状态，授权拒绝可打开系统设置。

## 稳定性与交互

- 区分权限拒绝、空内容、不支持、应用变化、超时和超限；来源异常不影响其他动作。
- 剪贴板与选中文本上限为 16 KiB UTF-8；超限整段拒绝，避免对截断 URL / JSON 执行操作。
- 已复制的 URL、路径与多选路径集合隐藏重复复制。不同打开目标保留来源标签，相同对象合并；执行目标与使用历史身份不变。
- Finder 读取有界并复验原应用实例；旧 Session / Revision 和迟到数据继续被拒绝。
- 修复设置开关/列表的点击反馈；关闭窗口后只保留安全状态元数据。

## 使用与验证

打开 `build/Anywhere.app`，使用 ⌘⌥Space 唤醒 Current App；加 Shift 进入 Universal。授权后重新唤醒即可再次采集。

安装包使用现有固定本机签名；它供这台 Mac 本地验证，不是面向其他 Mac 的公证发行包。完整验收项目与已知限制见 [0.4 验收记录](v0.4-context-acceptance.md)。
