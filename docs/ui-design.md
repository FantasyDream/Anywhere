# 共享 UI 与原生材质

当前实现：V0.12 / Build 15；最后核对：2026-10-23。页面行为以 [Launcher 交互](launcher-interaction.md) 为准，本页只说明视觉组件与平台边界。

## 页面任务与信息优先级

按页面任务判断优先级；这是交互设计假设，不把它称为用户频次统计。主要任务直接可见；低频操作有带文字 / 箭头的明确入口；错误、权限与未保存草稿不能被折叠规则掩盖。

| 页面 | 默认突出 | 按需展开 / 打开 |
|---|---|---|
| Launcher | 输入、当前范围、候选、执行 | 对象操作 `⌘K`、模式选择器、菜单浏览 |
| 文件搜索 | 查询、类型筛选、稳定列表、正文预览、打开 | 文件信息；无正文时直接展开元数据 |
| 剪贴板历史 | 查询、内容列表、预览、复制 | 条目操作 `⌘K`、预览详细格式与大小 |
| 悬浮剪贴板 | 搜索、快速选择、选中行复制与反馈 | 行内更多操作 / 右键 / `⌘K`：预览、删除、刷新；空列表保留入口 |
| 设置 | 分类、功能开关、目录、保存与异常 | 搜索规则、隐藏应用、正常采集状态、版本 / 能力、恢复 / 卸载、清空历史 |
| 任务 | 项目、运行状态、输出、停止 / 复制输出 | 命令与结果操作 `⌘K`、窗口选项、键盘帮助 |
| JSON Workspace | JSON、公式、计算结果、复制结果 | 输入区的 JSON 操作：复制变体、去转义与缩进 |

- 单一 Current App 分类用搜索框上方的应用标签交代范围，省去只有一个选项的标签栏；Context、Scope、分类顺序和切换键不变。
- 有菜单浏览入口的首页最多五条推荐，使完整菜单入口首屏可见；其余动作通过查询 / 分类 / 浏览可达。主要执行按钮与回车提示合成一个点击目标，显示在选中行右侧；对象的更多操作也随选中行展示，并继续支持 `⌘K`。返回只保留页头入口及 Esc；默认不在底栏重复返回 / 关闭，也不常驻“滚动”“本地处理”等泛化提示。
- `AppDisclosure` 用于次要信息与设置，原生 HTML `details.aw-disclosure` 用于 Web 同类场景。带文字与展开箭头，支持鼠标及 Enter / Space；展开不更改相邻开关。设置切换分类后保留已展开区域和草稿；这仅是 Flutter 呈现状态。
- 故障、待授权和需重启模块直接显示状态并展开操作；安装审批仍完整展示权限、默认取消，不省略确认。搜索不完整与来源异常仍保留原有可见提示。

## 组件与布局

- 所有页面使用 `ui/AppStyle`、公共图标、按钮、keycap 和设置组件；领域模块只提供内容及动作。
- Launcher 使用显著输入区、紧凑 Scope 标签和结果行，不显示通用页脚。选中态为中性的透明覆盖 / 边界，保留文字层级，不给每个图标套大底板。
- 普通搜索不显示结果条数。有更多操作时，行内直接显示 `… ⌘K`（其他平台 `Ctrl+K`），主操作仅保留文字；没有更多操作时仍显示回车图标。原应用菜单快捷键不在候选行展示；用户自定义的 Anywhere Action 绑定保留。只改变显示，原生菜单执行和定位数据不受影响。
- 文件页的数量、进度与异常重试放在类型筛选下方，归属于查询；执行和更多操作归属于选中项。
- 文件页扩展相同结构，类型标签复用 Scope 风格；右侧固定预览。文件类型外观来自 `ui/file_type_appearance.dart`，不影响 Rust 分类或执行身份。
- Settings 使用紧凑侧栏、统一行背景和桌面开关，标题 / 描述 / 状态 / 控件保持同一行体系；错误和权限引导就近呈现。草稿、保存、取消由 SettingsController / 页面管理。
- 插件 Detail / KeyValue 在同一 Launcher 材质内展示：紧凑返回栏、字段标签 / 值、可滚动正文与底栏；文字可选择。Esc 返回原查询，方向键滚动，不添加独立窗口 / 自定义色板或裸 Tab。
- Running Tasks 使用同一色板、紧凑列表与输出详情；窗口持久，支持关闭、最小化和调整大小。
- Clipboard History 使用列表约 68% / 预览约 32% 的搜索布局；预览宽度限制为 220–340。Clipboard Shelf 为右下角 420×560 的紧凑单列，复用会话、列表、预览与页框；单击选择，双击 / Enter 复制并保留焦点，只有 `⌘Enter` 显式返回原应用。`⌘1–9` 快选，`⌘K` 操作，`⌘Y` 预览；Esc 逐层返回，最终关闭。默认浏览不加载正文 / 图片，采集配置仅在 Settings。完整预览里的格式与保存大小收进“详细信息”；不读额外文件。
- 快捷键和返回沿统一导航：文件类型与 Scope 共用 Tab / Shift+Tab（兼容 Ctrl 组合）；文件页不增加空格预览或单独的预览模式。Web 页面内部的 Tab 由网页管理。

不固定要求所有页面相同密度。输入、结果、可操作控件和状态需要可辨认；透明效果不能让内容与桌面混为一体。大字体、窄屏、长路径通过布局与溢出回归验证。

## 状态与信息层级

- 搜索结果、菜单导航、剪贴板条目、任务列表和 Web 宿主 Actions 使用 `AppSelectionSurface`：选中有透明覆盖与细边框，悬停更轻；鼠标停在选中行上不再叠加第二层悬停底色。Scope / 文件类型 / Web 模式标签沿用相同选中颜色。
- 主标题使用主文字色；预览区标题统一为 12 / 500，说明、数量、时间使用辅助文字样式。代码预览沿用平台等宽字体与公共字号 / 行高。
- 按钮通过边框、统一圆角和键帽表达可操作性；被动状态标签不绘制按钮边框。Settings 继承公共按钮主题，不再覆盖成另一套字重和尺寸。
- 成功、提示、警告和错误分别使用对应颜色及图标，正文保持主文字色；共用提示声明为无障碍动态区域。Web 错误用错误色；Host 默认样式与 SDK 同步生成，不需要插件自行修补。
- 所有窗口沿用 Launcher 的中性玻璃遮罩；Settings / Tasks 不再使用过淡的独立遮罩。搜索页提示复用共享通知组件，保留简短正文、完整提示和权限入口。
- Web 工具栏、操作区和权限按钮支持换行；窄窗口保留全部操作，双栏在小于 560 宽时转为上下排列，矮窗口可滚动。编辑焦点使用明确边框，错误显示正文和语义边框，不用单纯降低透明度表达。
- 浅色原生材质上的普通文字与选中态文字保留对比度回归门槛（4.5:1），类型图标门槛为 3:1；这些是代表色测试，实际桌面材质仍需实机检查。

## Web 默认控件

Flutter `AppStyle` 与 Web 使用同一份 [设计参数](../resources/design-tokens.json)：正文字号 13、按钮字号 11、按钮高度至少 24、控件圆角 8，以及页头 72 / 工具操作栏 44、预览分栏比例和代码字体 / 行距、字重、内边距、边框和键帽参数。Flutter 键帽也消费这些公共参数。

[Web 控件规则](../resources/web-controls.css) 是唯一 CSS 来源，生成到 Host Dart 常量和 SDK 的 `styles/controls.css`。Host 在业务 HTML 之前自动注入，普通按钮、文本框、下拉框、标签、checkbox / radio、键帽无需插件导入样式即可适配。浏览器原生按钮 / 下拉外观被重置，悬停、按下、焦点和禁用态对齐 Flutter 设计参数；不再套一层独立浏览器焦点光圈。

公共规则使用低优先级选择器，允许第三方为局部组件自定义 CSS。背景透明依然由 Host 的画布适配负责，不由 CSS 控件层启用另一个模糊层。跨引擎文字栅格化和第三方自行覆盖的组件不承诺像素完全相同。

文字使用系统默认平滑方式，不强制 WebKit 灰度平滑；两端字重、字号 / 行距与文字颜色保持一致。不使用描边、阴影或额外不透明背景加粗文字。Host 与 SDK 消费同一份生成结果，插件无需添加字体补丁。

## 背景与可读性

Flutter 负责内容和控件，原生材质在其内容背后。Host `backdrop` 能力明确可用时允许透明底色；否则用不透明回退。共享页面不依赖 AppKit Widget。

搜索 / 二级 Actions / 模式选择器保持同一圆角、边界、内边距与文字层级。弹层需在实际窗口范围内渲染，不能把首屏小高度当作足够空间而裁掉菜单；模式选择以 Launcher 内导航层呈现。

浅色桌面下通过前景文字、局部覆盖和边界保持阅读对比。颜色、按钮尺寸和 keycap 的变更集中在公共样式，不由 Feature 各自绘制。

## macOS 实现

`WindowMaterial` 统一管理内容容器。源码在 compiler >= 6.2 且 macOS 26+ 的路径使用 `NSGlassEffectView.contentView`；其他路径使用 `NSVisualEffectView`，保留 macOS 12 的回退。

Flutter 内容是材质容器内部的真实子视图，不能只把玻璃作为同级背景然后假定获得相同效果。`WindowInputFocus` 维护内容 view / responder，窗口重父级、重复唤醒后重新连接输入；背景本身不接管业务键盘。

这说明当前代码如何使用系统 API，不代表未来 SDK、每种系统版本或所有辅助功能设置均已实机验收。没有把不再适用的“尚未接入玻璃”旧提案保留为现状。

## 生命周期与平台适配

Launcher / Settings 共享 Flutter engine；Running Tasks engine 按需创建。窗口尺寸来自 Host 展示状态，通过 DesktopHost 传 width / height，Rust 不决定像素。

其他平台可实现自己的材质，缺失能力仍渲染共享主题；Windows 窗口与输入仍需独立接入。材质、缩放、大字体、IME、重复唤醒、键盘焦点和 Reduce Transparency / 读屏分别验收，不以离屏截图替代原生测试。

文件预览的产品 / Quick Look 接口研究保存在 [预览调研](research/file-preview.md)，未接入的富预览与系统面板不作为现有 UI 能力。

编辑 / 查询工作区复用 File Search 页框：Flutter 的 `AppPageHeader` 用于 Launcher 与工具页面；工具页面有实际操作时可用 `AppPageFooter`，搜索页不再占用固定底栏，Web 的 `aw-workspace` / `aw-pane` 使用同一份尺寸参数。JSON 工具使用模式标签、左宽右窄分栏和轻量代码表面；取消双卡片重边框、强焦点矩形和重复常驻说明。返回与 Esc 保留在页头，Web 页脚保留加载状态与宿主工具选项，不常驻“本地处理”说明。

## 剪贴板操作与输入状态

历史页与悬浮剪贴板都没有固定底栏和结果计数。选中行复用 `AppRowActions`，显示复制和可见的 `⌘K` 更多操作入口；复制成功反馈在原行副标题，不改变行高或挤动列表。两者的条目操作都支持右键，菜单绑定打开时的条目身份；空列表在搜索区提供更多操作以便刷新。悬浮窗另外提供预览开关与复制返回命令，暂停状态显示在悬浮窗页头。双击识别仅覆盖内容区域，行内按钮即时响应。

历史页与悬浮页共用搜索 / 选择会话。中文组词期间暂停搜索与条目操作，提交后再查询；过期搜索和预览不能覆盖已提交的新输入。已选条目的重复点击、边界方向键复用现有预览，继续保持选中行可见。复制成功立即反馈，不等待历史刷新或图片预览；只有明确的“复制并返回”命令才切回目标；删除仍刷新列表。隐藏页不自动抢输入焦点，也不能打开 Actions。
