## 实现契约

- Rust `HistoryPolicy` 管理策略，`HistoryService` 管理时钟、采集 epoch、自动恢复及执行前复验；SQLite 管理迁移、持久策略、过期删除和用量聚合。Flutter 仅发送操作、读回状态和显示本地化信息。
- 设置页是唯一配置入口。历史页与悬浮窗仍用于搜索、选择、预览和使用条目，不增加采集开关或新 Scope。
- 暂停保留已有历史，启用状态与实际正在采集分开显示；关闭记录会取消定时恢复。恢复仅读取代数作为新基线，不保存当时的剪贴板内容。
- 暂停、清空、禁用或策略变化撤销在途采集 / 预览。暂停到期后的首次代数基线以后台维护实际执行时刻为准；尚未建立基线时宁可跳过内容，不补录无法证明复制时刻的值。
- 保留时间按最近一次复制时间计算。默认维持已有的 1,000 条 / 128 MiB 容量规则，不自动给旧记录加期限。缩短期限且已有记录时先确认；生效后立即删除过期条目，延长期限不恢复已删除内容。
- 搜索、详情、预览返回前、恢复复制前均复验过期记录。后台约每分钟清理过期内容，应用退出期间不运行；重新启动及后续访问继续检查。
- 删除联级清理全部已保存格式，保持 `secure_delete=ON`；这不是备份、文件系统快照或系统剪贴板的安全擦除承诺。用量是逻辑数据量，不是数据库文件大小。
- 历史策略、唤醒自动填入的 15 秒期限、窗口隐藏保留的 15 秒期限彼此独立。配置策略不会开启原本关闭的记录。
- schema 从 v1 / v2 事务迁移至 v3，保留条目 ID、格式及采集开关。旧版应用不能直接读取更新后的历史数据库；不要通过覆盖数据库来回退。

## 验证与剩余工作

自动化覆盖定时暂停跨重启、到期恢复不补录、暂停时迟到采集被撤销、关闭记录取消恢复、过期后搜索 / 预览 / 复制拒绝、预览解码期间过期或策略变化、期限缩短立即删除、格式级联删除和 v2 迁移。

Flutter 回归覆盖采集开关与暂停状态分离、设置异步读回、删除期限确认 / 取消、中英提示及原有清空流程。补充隐藏后停止刷新、暂停截止时间附近才读回、写入排队不丢失，以及测量等待原生显示 / 当前帧、取消和默认关闭的回归。Build 4 增加历史页 / 悬浮窗计时：列表可用不等待预览、组合态与迟到响应排除、隐藏 / 销毁取消，以及独立 engine 的显式开启和传输失败降级。完整门禁 `scripts/check.sh` 通过：Rust 576 项通过、6 项既有忽略；Flutter 395 项通过；规范、原生、架构、Clippy、Web SDK / 示例检查通过。单元测试不代替实际窗口验收。

设置页不再每 2 秒固定刷新暂停状态：可见时在截止时间附近读回，隐藏停止，重新打开重新读回；暂停到期后的异常恢复仅在可见时短间隔重试。Rust 继续独立负责定时恢复与保留策略。后台读取与配置写入串行，读取合并不吞掉写入，关闭设置等待最后一次写入及读回。

Build 2 使用独立数据目录、100 条合成文本验收，未读取个人历史。确认历史筛选 / 跟随预览、暂停菜单、暂停 / 恢复、设置切页、期限缩短确认及取消、中英布局；完成 50 次 Launcher 查询替换和 20 次历史页进入 / 返回。结束前采集已关闭；隔离数据库仍为 100 条，策略未改变。Build 3 修正英文单复数，Build 4 已在实际期限菜单确认 `1 day` 正确。

Build 4 使用 1,000 条合成文本和预置的 7 天期限启动真实 App，自动删除过期条目后剩余 350 条，保存格式也从 1,000 份联级清理至 350 份。通过设置页实际暂停 5 分钟，正常退出后显式重启隔离实例，确认截止时间不变；不改系统时钟，等待真实到期后，界面自动移除暂停状态。将期限延长为 30 天仍为 350 条，不恢复已删除数据；临时采集已关闭。细节见 [Build 4 验收记录](benchmarks/clipboard-policy-acceptance-v0.13-build4-2026-10-23.json)。

验收工具在正常退出后读取状态会自动重启未带环境变量的默认实例；该实例已停止，未向它执行测试配置或剪贴板写入。只读元数据确认默认历史库为 schema v3；缺少启动前版本，不能断言此次是否发生迁移，旧包也不能直接读回 v3，请使用本阶段兼容包。后续显式指定独立目录再重启，退出后使用只读进程检查。不要将默认实例的正常启动行为等同于隔离目录操作，方法见 [独立实机测量](development.md#独立实机测量macos)。
