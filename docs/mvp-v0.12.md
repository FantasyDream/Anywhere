# V0.12：中英国际化与拼音检索

日期：2026-10-21。分支：`codex/dev-0.12-i18n`。基线为 V0.11 / Build 51（收尾提交 `5bb7c9a`）。本阶段分批迁移，不把基础设施接通视为所有页面翻译完成。

## 不变的契约

- UI 语言只改变呈现，不参与 ActionId、CandidateId、菜单定位、Usage、快捷键或权限身份。
- System / 简体中文 / English，旧设置缺字段时跟随系统；不支持的系统语言回退英文。主窗口与独立 Flutter engine 同步语言偏好，不轮询文件、不重新启动 engine。
- 外部应用名、菜单标题、用户文本、文件名、路径和命令输出保留原文；开发动作保留 Git / Maven / JSONPath 等行业名称。
- 搜索与语言选择独立：两种语言的内置名称均可查；拼音只用于显示名称及明确的搜索别名，不转换隐藏标识、执行地址或剪贴板全部正文。
- 文件搜索继续 Spotlight 快速路径 + 完整遍历，无新持久文件索引，保持稳定列表和固定预览。拼音必须进入遍历匹配，不能仅在 UI 过滤结果。

## 实施状态

I1 开源选型、I2 语言基础、I4 共享拼音匹配已完成首轮工程实现。I3 已迁移设置导航 / 通用语言设置、主搜索提示、文件类型和预览标签、剪贴板主要标签；SDK 提供语言信息和变化订阅，JSON 0.5.0 使用内嵌 i18next 资源。研究与取舍见[开源选型](research/i18n-pinyin.md)。

当前仍有英文文案，**V0.12 尚未整体完成**。接下来按下面顺序推进 I3，再做 I5 GUI：

1. 内置 Action 的显示名称及双语搜索别名，按稳定 ID 呈现，禁止通过英文标题反查翻译。
2. 设置详细内容 / 确认对话框、任务页、搜索状态 / 错误 / 空态、来源说明与预览元数据。现有外部诊断保留原文，后续通过类型化消息迁移，不把翻译放进 Core 的全局状态。
3. 原生应用菜单与辅助说明、Web Host 确认面板；旧 Web 包可继续使用其原语言。
4. 真实切换、多个窗口联动、中文 IME 与长文案布局验收。主程序完整迁移前，不把当前包作为最终国际化交付。

## 明确不纳入

不翻译第三方应用菜单，不按拼音猜测菜单执行位置，不为全文剪贴板建立拼音副本；不引入云翻译、运行时下载词库或新 UI DSL。第三方包的翻译由包提供，宿主只给语言与更新通知；没有翻译的旧包继续使用原文。
