# V0.12：中英国际化与拼音检索

日期：2026-10-23。开发分支：`codex/dev-0.12-i18n`，最终集成目标为 main。基线为 V0.11 / Build 51（收尾提交 `5bb7c9a`）。本阶段分批迁移，不把基础设施接通视为所有页面翻译完成。

## 不变的契约

- UI 语言只改变呈现，不参与 ActionId、CandidateId、菜单定位、Usage、快捷键或权限身份。
- System / 简体中文 / English，旧设置缺字段时跟随系统；不支持的系统语言回退英文。主窗口与独立 Flutter engine 同步语言偏好，不轮询文件、不重新启动 engine。
- 外部应用名使用应用包提供的对应语言名称，缺少翻译时保留原名；菜单标题、用户文本、文件名、路径和命令输出保留原文。开发动作保留 Git / Maven / JSONPath 等行业名称。
- 搜索与语言选择独立：两种语言的内置名称均可查；拼音只用于显示名称及明确的搜索别名，不转换隐藏标识、执行地址或剪贴板全部正文。
- 文件搜索继续 Spotlight 快速路径 + 完整遍历，无新持久文件索引，保持稳定列表和固定预览。拼音必须进入遍历匹配，不能仅在 UI 过滤结果。

### 系统应用名称

- macOS 15.4 及以上通过 Bundle 的公开指定语言接口读取 `InfoPlist.loctable` / `InfoPlist.strings`；旧系统和旧 SDK 使用 `InfoPlist.strings` 兼容路径，不改进程的语言偏好、不解析私有格式。中文、英文名称随应用目录一次采集。
- Rust 将两种名称加入既有别名与拼音匹配；Flutter 按当前语言选择显示名称，切换语言无需重扫。主候选列表与快捷键应用选择器共享显示规则；无对应翻译的应用保留原名。
- 名称不参与应用 CandidateId、UsageId、Bundle ID、启动路径或图标来源的生成。第三方应用菜单仍使用应用实际提供的菜单文字。

### I3 文案与边界整理

- 主程序采用成对 ARB 文案，生成类型化 Flutter 访问器；清理未调用的条目，当前资源数量由生成检查记录。31 个原生固定文案与 Automation 用途说明从同一来源生成 Apple `.strings`，通过 Bundle 选择语言，不维护另一份手写翻译。
- 30 个静态内置动作由所属模块声明 `localized_titles`，注册时加入检索别名；匹配和快捷键目录携带双语标签。中文名称、全拼、首字母都使用现有 Rust 搜索，界面不通过英文标题反查翻译，也不改变动作 ID / Usage。
- Web 安装权限与逐次确认改为类型化能力 / 操作，由 Flutter 生成中英文说明；不依赖英文句子判断授权。语言切换不会确认操作，也不会重建 Web 文档。
- 来源状态、搜索进度、权限失败、剪贴板提示和设置校验在渲染时选择语言。设置分区显式传入图标，避免翻译后的标题影响分区逻辑。
- 文件名、路径、用户规则名称、菜单文字、脚本 / 任务名称与命令输出保留原文。系统或第三方返回的技术诊断也保留原文，避免翻译过程改变排障数据。未接入语言资源的旧插件不会被宿主强行翻译。
- I5 的工程门禁与构建 / 实机结果记录在下方；真实中文输入法组合输入、VoiceOver 与更多系统版本的发行矩阵须分别记录，不能由粘贴输入或构建成功替代。
