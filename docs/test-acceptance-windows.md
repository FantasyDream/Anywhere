# Windows 11 桌面验收指南

供代理在已解锁的 Windows 11 x64 桌面上模拟用户操作。先核对
[Windows 功能实现进度](windows-progress.md)和[运行与构建指南](windows.md)。
用例初始为 Pending，每轮结果只归属该轮 EXE、测试环境和输入方式。
macOS 另见 [macOS 桌面验收指南](test-acceptance-macos.md)。

## 代理执行规则

1. 先确定受测产物、测试范围和环境，打开桌面控制工具，确认能看见整个桌面，
   并能把键盘事件发送给当前前台窗口。准备数据后，从 Explorer 或用户可见入口启动。默认目录场景使用专用测试用户。
2. 按用例依次点击、拖动、切换应用或发出真实桌面键盘事件。操作前确认焦点和选区；
   每次等待窗口、首批结果或最终结果进入明确状态，再观察系统副作用。可用脚本准备
   夹具、查询进程和采集日志。通过脚本写配置、直接调 API、改焦点、设剪贴板或启动
   目标应用只算准备或工程证据。
3. 记录输入来自代理桌面注入、远程桌面还是实体键鼠。IME 使用系统拼音，发送分开的
   字母键并观察候选窗、组词、提交和取消。粘贴汉字或调用文本填充不能覆盖组词；
   工具无法传递按住、按键抬起或硬件状态时，保留相应子项 Blocked，交由有条件的
   操作者复验。单屏或远程桌面也不能覆盖真实双屏、混合 DPI 或硬件材质。
4. 桌面锁定、缺少第三方程序或无法观察预期结果时，记录 Blocked 与缺少条件，并继续
   无依赖用例。观察到行为偏差时记录 Fail、首个出错步骤和复现次数。遇到错误目标执行、
   越权或数据写坏，保留证据并停止受影响的动作链。
5. 用专用测试用户或虚拟机做登录项、Explorer 重启、读屏及缺失运行库试验。用例用
   假数据。结束后退出本轮实例，恢复测试前的输入法、主题、透明效果、搜索索引选项和
   剪贴板状态；保留脱敏证据。

## 被测包与夹具

- 记录 Git HEAD、工作树差异、EXE 与 ZIP 的 SHA-256、Windows 版本/内部版本、
  CPU 架构、屏幕布局及 DPI、IME、WebView2 Runtime 和可选工具版本。在任务管理器
  核对前台版本所属进程；先退出已有的 Anywhere 测试实例。
- 为普通用例设置绝对路径 `ANYWHERE_DATA_DIR`，从该环境启动 EXE 或启动
  Explorer 可继承环境的测试会话。也可在 PowerShell 中用下列命令启动正常界面，
  再切换到桌面执行用例。登录项和默认单实例用专用用户的默认数据目录。

```powershell
$zip = Resolve-Path .\build\windows\Anywhere-windows-x64.zip
Get-FileHash -Algorithm SHA256 -LiteralPath $zip
$qaRoot = Join-Path (Resolve-Path .\build) ("windows-qa-" + (Get-Date -Format 'yyyyMMdd-HHmmss'))
Expand-Archive -LiteralPath $zip -DestinationPath $qaRoot
$exe = Join-Path $qaRoot 'Anywhere\Anywhere.exe'
Get-FileHash -Algorithm SHA256 -LiteralPath $exe
Get-AuthenticodeSignature -LiteralPath $exe | Select-Object Status
$qaPreviousDataDir = $env:ANYWHERE_DATA_DIR
$qaPreviousTaskbar = $env:ANYWHERE_QA_SHOW_IN_TASKBAR
try {
    $env:ANYWHERE_DATA_DIR = Join-Path $qaRoot 'data'
    $env:ANYWHERE_QA_SHOW_IN_TASKBAR = '1'
    Start-Process -FilePath $exe
} finally {
    $env:ANYWHERE_DATA_DIR = $qaPreviousDataDir
    $env:ANYWHERE_QA_SHOW_IN_TASKBAR = $qaPreviousTaskbar
}
```

`ANYWHERE_QA_SHOW_IN_TASKBAR=1` 用于只能操作任务栏窗口的桌面代理。仍需从
Explorer 双击产物启动并记录该开关。默认托盘式样式和登录启动场景应另起一轮，
不设置此开关。

- 建立 `目录 A`、`目录 B` 两个根，以及一个未授权的同级目录。放入
  `报告 2026.txt`、`季度[报告].md`、`Café.txt`、同名不同目录的文件、小 PNG、
  PDF、带 Windows Hidden 属性的条目，以及足量同前缀文件以跨页。用资源管理器
  创建或核对快捷方式、测试回贴目录。需要权限条件时使用当前测试用户可控制的夹具。
- 准备两个能产生不同 Context 的 Explorer 标签页、一个可选中文本的编辑器、一个
  支持的浏览器、可信本地测试插件包和项目夹具。插件、Git 及项目测试只使用自建数据，
  固定版本和可预期输出。
- 冒烟顺序为 W-ENV-01 → W-LCH-01/02 → W-KEY-01 → W-APP-01 →
  W-SET-01 → W-FILE-01/02 → W-CLIP-01 → W-ENV-03。之后按改动复验其余模块。
