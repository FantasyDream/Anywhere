## 构建与打包

在仓库根目录执行：

```bash
scripts/check.sh
ANYWHERE_APP_OUTPUT="$PWD/build/Anywhere-dev-0.5.app" scripts/build-macos.sh
scripts/package-macos.sh build/Anywhere-dev-0.5.app
```

打包脚本要求显式指定 `build/` 内的 App，检查源码与 App 版本以及固定签名。ZIP 验证成功后才替换交付文件；架构标签从实际主程序读取，同时生成 SHA-256 校验文件。

本次交付：

- App：`build/Anywhere-dev-0.5.app`，可直接运行。
- ZIP：`build/Anywhere-dev-0.5-macos-arm64.zip`，用于传输。
- 校验文件：`build/Anywhere-dev-0.5-macos-arm64.zip.sha256`。
- 原 `build/Anywhere.app` 保留为 0.4.0+3。

验证下载或复制后的 ZIP：

```bash
cd build
shasum -a 256 -c Anywhere-dev-0.5-macos-arm64.zip.sha256
```
